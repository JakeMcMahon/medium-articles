Why Incumbents Were
Vulnerable

Mixpanel and Amplitude are closed-source. When you send event data to

Is it used to train AI models?

For general SaaS, this is annoying. For healthcare, it’s
disqualifying.
Developer reaction:
“I don’t trust black-box

Why HogQL +
Database Connectivity Changes Everything
The Query Problem
Both Amplitude and PostHog can export data. But querying differs
dramatically.
With Amplitude:
To analyze events, you need: -
Export to S3 via Export API (infrastructure setup) - Write Python
scripts against S3/API - Manual joins with external data (Stripe,
Postgres, CRM) - Query limitations without custom infrastructure
Real workflow:
“Which users are at churn risk?”
requires: 1. Export 30 days of Amplitude events to S3 (batch job) 2.
Write Python script to aggregate activity patterns 3. Query payment
system separately (Stripe API) 4. Join in pandas or SageMaker (manual
data alignment) 5. Train ML model offline
With PostHog Cloud:
HogQL queries ClickHouse
directly, and you can connect your own databases (Postgres, MySQL) for
direct SQL joins.

When Open-Source
Works (and When It Doesn’t)
Open-Source Works For:
Developer/technical audiences
- Appreciate ability
to read code - Value self-hosting options - Contribute to projects they
use
Privacy/security-critical products
- Healthcare and
medical compliance - Financial services - Government/defense - Any
industry requiring audit trails and regulatory compliance
Infrastructure/tools markets
- Developer tools -
Data platforms - Analytics and observability - DevOps tools
When community contributions are valuable
- Features
(extend functionality) - Integrations (connect to other tools) -
Documentation (explain usage)
Open-Source Doesn’t Work For:
Non-technical audiences
- Don’t value open-source -
Don’t self-host - Don’t contribute code
Self-hosting impractical
- Complex managed services
- Requires specialized infrastructure - High operational burden
IP protection critical
- Proprietary algorithms are
competitive moat - Trade secrets in code - Patent strategy
Community management overhead too high
- 1,000s of
GitHub issues to triage - Pull request review burden - Documentation
maintenance - Support forum management
Scale Insights:
Open-Source Didn’t Fit
When evaluating whether to open-source Scale Insights (Amazon PPC
SaaS), we assessed using PostHog’s lessons:
Target audience:
Amazon sellers (non-technical,
don’t value open-source)
Self-hosting:
Impractical (sellers want managed
solution, not infrastructure)
Community:
Limited (sellers won’t contribute
code)
IP:
Optimization algorithms are competitive moat
(shouldn’t open-source)
Decision:
Stay closed-source. Focus on product-led
growth (free trial), not open-source distribution.
The lesson:
Open-source isn’t universal. Know when
it doesn’t fit.
